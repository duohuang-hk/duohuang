# 爆款标题批量调研分析工作流

## 前置条件

使用本工作流前，先加载 hk-douyin-wenan-1：

```
skill_view('hk-douyin-wenan-1')
```

本工作流是「选题创作五层来源」之外的第六来源：从平台批量搜索获取爆款标题数据，经模式分析后反推出新选题方向。

## 触发时机

- 用户要求「在抖音搜索框搜XX关键词，收集高赞标题」
- 用户要求「帮我找50条高赞视频，分析高频词和句式」
- 用户要求「按XX方向出大量爆款选题」
- 感觉选题枯竭，需要外部数据驱动的新角度

## 工具依赖

- **anysearch CLI**（bash 版本）— 用于 site:douyin.com/video + 关键词搜索
- 可选的替代方案：直接使用 TikHub API 搜索端点（需配置 API Token）

## 完整工作流

### 第一步：多关键词批量搜索

根据业务方向确定 4-6 组搜索关键词，每组用 anysearch 搜索 site:douyin.com/video：

```bash
# 关键词规划原则：
# - 覆盖不同痛点维度（痘痘/痘印/闭口/敏感/毛孔）
# - 覆盖不同用户行为（反复/怎么治/怎么预防）
# - 覆盖不同内容类型（干货/呈现/避坑）

# 示例：痘痘肌方向
搜索关键词1: "site:douyin.com/video 痘痘 反复 好了 又长 获赞"
搜索关键词2: "site:douyin.com/video 闭口 粉刺 毛孔 祛痘 万赞"
搜索关键词3: "site:douyin.com/video 痘印 痘坑 怎么 去 消 淡化 获赞"
搜索关键词4: "site:douyin.com/video 美容院 祛痘 针清 问题肌 老板"
搜索关键词5: "site:douyin.com/video 敏感肌 长痘 屏障 受损 修护"
搜索关键词6: "site:douyin.com/video 红肿 痘痘 怎么 处理 消炎"

# 也可以用 batch_search 并行执行
anysearch_cli.sh batch_search --queries '[
  {"query":"site:douyin.com/video 痘痘 反复 获赞","max_results":10},
  {"query":"site:douyin.com/video 闭口 粉刺 祛痘 万赞","max_results":10}
]'
```

每条搜索可返回约 10 条结果。5-6 组搜索即可集到 50+ 条标题。

**注意：** 抖音的浏览器登录页有 CAPTCHA 防护，无法直接访问搜索结果页。替代方案是用 search engine 的 site: 语法从搜索结果中间接抓取视频标题。

### 第二步：提取标题和点赞数据

从搜索结果的摘要中提取：

- **视频标题**：搜索结果的标题行（第一个加粗文本），通常就是抖音视频的 desc 或关键词提炼
- **点赞数**：当搜索结果包含形如「收获了X万个喜欢」或「获赞X万」的文本时提取
- **视频链接**：douyin.com/video/xxxx 格式
- **作者信息**：部分结果会附带昵称和粉丝数

提取后整理成纯标题列表，去掉编号和 URL 干扰。

### 第三步：高频用词统计

对标题列表做词频分析，重点关注：

| 词类 | 关注点 | 业务含义 |
|------|--------|---------|
| 痛点名词 | 痘痘、痘印、闭口、粉刺、痘坑、毛孔 | 用户最焦虑的是什么 |
| 状态副词 | 反复、一直、又、还是、越、再 | 用户处在什么阶段 |
| 情绪动词 | 怕、别再、千万别、困扰、焦虑 | 用户情绪浓度多高 |
| 方法词 | 怎么办、怎么、方法、步骤、教程 | 用户在找什么 |
| 否定词 | 不、别、不是、没 | 用户在否定什么 |

统计方法：用 Python 逐词 count，或用 `grep -o` + `sort | uniq -c` 在终端做。

### 第四步：高频句式分类

将 50+ 条标题按句式结构归类，问题肌/美业赛道常出现的 7 大爆款句式：

| 句式类型 | 模板 | 示例 |
|---------|------|------|
| 反问/诊断式 | "XXX怎么办？/XXX到底怎么XXX？" | 长痘就像绝症一样好不了怎么办？ |
| 原因揭露式 | "XXX的根源是XXX/XXX才是根源" | 脸上爆痘别慌！中焦堵了才是根源 |
| 否定/纠偏式 | "不是XXX/XXX不可能XXX" | 祛痘不可能一步到位 |
| 劝告/警示式 | "千万别XXX/再XXX就XXX" | 千万别让痘痘影响你的心情 |
| 经验干货式 | "X年经验/保姆级教程" | 9年痘肌经验总结内服这样吃才有效 |
| 爽感反转式 | "终于XXX/再也不怕了" | 烂脸终于好了 |
| 盘点清单式 | "X种XXX/四大XX" | 建议常备的三种祛痘药膏 |

### 第五步：筛选选题方向

从分析结果中挑出 2 个差异化的选题方向。筛选标准：

1. **这个方向有高频痛点支撑** → 这个词在标题中反复出现
2. **这个方向还没有被做滥** → 现有标题对这个角度的回答不够好
3. **这个方向适合你的业务** → 实体店老板能承接这个信任

交叉确认：高频词 + 高频句式 + 你的业务定位 = 选题方向

### 第六步：批量出标题

每环节给选题方向，用高频词+高频句式组合生成 20 条标题：

```
1. 确定选题方向的「高频词池」（5-8个核心词）
2. 确定要套用的「句式模板」（3-4种合适句式）
3. 每个标题 = 高频词池 × 句式模板 组合
4. 确保各标题之间的切入角度有差异
```

## 一次完整执行的参考产出

### 产出1：50+原始标题清单（分门别类）
### 产出2：高频用词 TOP 20 表（含词频）
### 产出3：7 大句式模板 + 每条对应的示例标题
### 产出4：2 个选题方向（每方向给出筛选理由）
### 产出5：每方向 20 条爆款标题（合计 40 条）

## 与 hk-douyin-wenan-1 的衔接

完成本工作流后，输出的 40 条标题可进入 wenan-1 的阶段一「选题」流程：

1. 告知用户：「基于平台数据调研，挖到 2 个方向各 20 条爆款标题」
2. 让用户从此 2 个方向中选 1 个
3. 按 wenan-1 的 3 个选题标准做二次过筛
4. 进入阶段二搭框架

## 已知坑

- **抖音有 CAPTCHA 保护**：无法直接用浏览器打开 douyin.com 做搜索交互。必须用 search engine 的 site: 语法从外部爬结果
- **搜索结果的标题不一定准确**：有些搜索结果是编辑后标题，不是原始视频 desc。但趋势和模式足够用
- **点赞数不确定是否 >1000**：搜索结果中点赞数据不全。为保险，以高出 1 万赞的标题为分析主体
- **anysearch 限速**：免费版每次返回 10 条结果，需要多组关键词并行才能快速凑够 50 条
